# 录入目录

把「录入目录」当作一条固定指令。

当用户给出**带标题的视频页面截图**和**视频链接**时：

1. 先从截图读出完整标题。  
   - 标题看不清、被截断且无法核实、或页面上找不到标题：先向用户反馈，不要猜测录入。
2. **先标号，再落盘。**  
   - `files/单视频收录/` 里，每个视频一个子目录，目录名前加序号：`01_`、`02_`、`03_`……  
   - 该视频的一系列文件也要标号；docx 文件名用**简短标题**，如 `01_快速离心.docx`、`02_页面截图.png`、`03_二维码.png`……  
   - `files/综合拓展/视频综合目录.docx` 里，每条内容用 `1.` `2.` `3.` 序号累加，不覆盖已有条目。
3. 写入单视频收录：  
   - 标题、用户给的超链接、本视频二维码、页面/界面截图、截图信息  
   - 若有视频间联系：写中文描述、精准空降链接、略小的精准二维码，以及对应动作图（图与二维码同高、同一水平排）
4. 追加到综合拓展：  
   - 只加：序号、视频标题、本视频二维码  
   - 留出「评论空间」「细节关注」两栏  
   - 视频间联系只写中文描述和动作细节图，**不放** a滑步 / b交叉步 / c连续滑步（双滑步）的链接和二维码  
   - 动作图高度（保持比例）与二维码一致，分组水平排列（如图二三一组、图四五一组）

下一次继续发视频页截图 + 链接，或再次说「录入目录」即可。
