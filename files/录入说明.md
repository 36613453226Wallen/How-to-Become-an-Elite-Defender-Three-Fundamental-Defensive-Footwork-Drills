# 录入目录

把「录入目录」当作一条固定指令。

当用户给出**带标题的视频页面截图**和**视频链接**时：

1. 先从截图读出完整标题。  
   - 标题看不清、被截断且无法核实、或页面上找不到标题：先向用户反馈，不要猜测录入。
2. 写入第一个文件夹 `files/单视频收录/`：  
   - 每个视频单独一个子目录 + 一份 docx  
   - 文档里只有这一条视频：标题、用户给的超链接、生成的二维码、页面截图、截图上的相关信息
3. 追加到第二个文件夹里的综合性文档 `files/综合拓展/视频综合目录.docx`：  
   - 只加：视频标题、二维码  
   - 留出「评论空间」「细节关注」两栏  
   - **累加**，不覆盖已有条目  
   - 单视频动作细节不在此列

下一次继续发视频页截图 + 链接，或再次说「录入目录」即可。
